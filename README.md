# 🧬 DNA Analyzer Tools

A simple Python package to analyze DNA sequences. 
This project can validate DNA, convert DNA to RNA, find length, GC content, base count, base percentage and reverse complement.

## ✨ Features

- Validate DNA sequence (only A, T, G, C allowed)
- Convert DNA to RNA
- Find DNA length
- Calculate GC Content (%)
- Count A, T, G, C bases
- Calculate Base Percentage
- Find Reverse Complement
